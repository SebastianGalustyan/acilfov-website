Pagina de pornire: index.html
Conținut: 37 de pagini HTML, dc-lite.js (interactivitate), folderul assets/ (logo), robots.txt.
Fiecare pagină are sus banda „Propunere de redesign – nu este site-ul oficial Apă Ilfov”
și nu apare în Google (noindex + robots.txt).

Publicare pe GitHub Pages:
1. github.com → New repository → nume (ex. acilfov-redesign) → Public → Create repository.
2. Pe pagina repository-ului: „uploading an existing file” → trageți TOATE fișierele din acest folder
   (inclusiv folderul assets) → Commit changes.
3. Settings → Pages → Branch: main, folder: / (root) → Save.
4. După 1–2 minute, linkul apare în Settings → Pages: https://NUMELE-TAU.github.io/acilfov-redesign/

Linkurile către PDF-uri sunt încă "#" și trebuie completate cu adresele reale.
